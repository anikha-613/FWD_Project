# Cyber Lost & Found – Digital Access Recovery System

## Project Overview
Cyber Lost & Found is a web-based platform that helps users recover lost digital accounts securely. 
Students can submit recovery requests, and administrators can verify and manage these requests through an admin dashboard.

## Objectives
- Provide a platform to report lost digital accounts
- Simplify account recovery process
- Reduce manual workload for administrators
- Maintain organized digital records

## Features
- Student Portal
- Admin Portal
- Recovery Request Form
- Request Management System
- User-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder.
3. Open `project.html` in a web browser.

## Future Improvements
- Database integration
